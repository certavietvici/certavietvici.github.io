# certavietvici.github.io

This is a résumé/curriculum vitae GitHub Pages website using html for an experience DoW IT contractor seeking to move into formal subcontracting with prime contractors versus W2 or 1099 work. It demonstrates registration with sam.gov, completion of course required for the roles needed to hold an FCL, asserts extensive, specialized experience supporting DoW on 4 continents.

Style is minimalist with a banner similar to those found on Government networks, stating the principal purpose of the page, instead of a classification with caveats.
